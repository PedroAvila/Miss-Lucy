# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is **not a software project** — it's a personal English-learning journal/archive for the user (Pedro), tracking ~1.5+ years of self-study. There is no build, lint, or test tooling, and none should be added unless explicitly requested. Content is a mix of plain-text notes, a markdown study plan, a `.docx`, and photos of handwritten class notes.

## Structure

- `plan-ingles.md` — the current weekly study plan (in Spanish). States the user's stated goal, methodology, and weekly schedule. Read this first to understand what the user is actively working toward (currently: shifting from passive vocab/grammar study to active speaking practice via HelloTalk, shadowing, and self-talk).
- `palabras-ingles/` — vocabulary lists, phrases, and short stories used for vocab building.
- `Francisco-Ochoa/` and `Vladimir-Victorio/` — materials organized by instructor/course (lessons, PDFs, homework).
- `conversacion/`, `canciones/`, `Diario/` — conversation practice, song lyrics/translations, and diary/sentence-writing exercises.
- Dated folders (e.g. `27-01-2024/`, `23-03-2024/`) — photos of handwritten notebook pages from classes on that date.
- `abecedario.txt`, `DiasDeLaSemana.txt`, `Ingles.txt` — foundational reference notes (alphabet, days of the week, general notes).

## Working in this repo

- Content is almost entirely in Spanish (the user's native language) with English being studied. Keep new notes/explanations in Spanish unless the content itself is the English being practiced, matching the existing files' convention.
- When adding vocabulary, follow the format already used in `palabras-ingles/` and the convention set in `plan-ingles.md`: each new word/phrase should come with an example sentence, not just the isolated word.
- Preserve the existing organizational pattern (by date, by instructor, or by topic) rather than introducing a new structure — check which pattern an existing sibling file/folder uses before adding new content.
- Do not reorganize, rename, or delete existing notes/photos unless explicitly asked — this is a personal historical record of the user's study progress.
