# 📜 La Leyenda del Orden en Inglés (Guía de Referencia)

> **Nota para el desarrollador:** Esta es tu documentación de referencia (`README.md`) para la sintaxis básica del inglés. Guarda este archivo y consúltalo antes de "compilar" tus oraciones.

## 🧠 Aclaración Inicial (Desmintiendo el mito)
- ❌ **Mito:** "El presente simple no se invierte, pero los adjetivos sí".
- ✅ **Realidad:** Las oraciones **afirmativas** (en cualquier tiempo verbal) **NUNCA** se invierten. Los adjetivos no invierten la oración, solo cambian de lugar *dentro* del objeto. La **única** inversión real (Verbo antes que Sujeto) ocurre en las **preguntas**.

---

## ⚙️ Las 4 Reglas de Sintaxis Base

### 1️⃣ AFIRMACIONES: El "Comportamiento por Defecto" (`Default`)
- **Regla:** `Sujeto` + `Verbo` + `Objeto/Complemento` (S + V + O)
- **Cuándo aplica:** En **TODOS** los tiempos verbales afirmativos (Presente Simple, Pasado, Futuro, etc.).
- **Ejemplo:** `I` (S) + `write` (V) + `clean code` (O).
- **💡 Clave:** El sujeto **siempre** va primero. Nunca se invierte.

### 2️⃣ NEGACIONES: "Inyección de Auxiliar" (No es inversión total)
- **Regla:** `Sujeto` + `Auxiliar + NOT` + `Verbo (forma base)` + `Objeto`
- **Cuándo aplica:** Cuando niegas una acción.
- **Ejemplo:** `I` (S) + `do not` (Aux) + `write` (V) + `dirty code` (O).
- **💡 Clave:** El sujeto **SIGUE** yendo antes que la acción. Solo "inyectamos" el auxiliar negativo (`don't`, `doesn't`, `didn't`) entre el sujeto y el verbo.

### 3️⃣ PREGUNTAS: La "Inversión Real" (`Override`)
- **Regla:** `Auxiliar` + `Sujeto` + `Verbo (forma base)` + `Objeto`?
- **Cuándo aplica:** Cuando haces una pregunta directa (Yes/No questions o Wh- questions).
- **Ejemplo:** `Do` (Aux) + `you` (S) + `write` (V) + `clean code` (O)?
- **💡 Clave:** Esta es la **única** situación común donde el verbo (o su auxiliar) salta y se pone **antes** del sujeto. Aquí sí hay inversión.

### 4️⃣ ADJETIVOS: "Micro-ajuste de Sintaxis" (No afecta a la oración)
- **Regla:** `Adjetivo` + `Sustantivo`
- **Cuándo aplica:** Siempre que describas algo.
- **Ejemplo:** `clean` (Adj) + `code` (Sustantivo).
- **💡 Clave:** La oración mantiene su estructura S+V+O. Lo único que cambia es el orden *interno* del objeto. En español el adjetivo va después ("código limpio"), en inglés va antes ("clean code").

## ⚡ Resumen Visual Rápido (Cheat Sheet)

| Tipo de Oración | Estructura | Ejemplo |
| :--- | :--- | :--- |
| **Afirmativa** | **S** + V + O | **She** writes clean code. |
| **Negativa** | **S** + Aux+NOT + V + O | **She** doesn't write dirty code. |
| **Pregunta** | **Aux** + S + V + O? | **Does** she write clean code? |
| **Con Adjetivo** | S + V + (**Adj** + Sustantivo) | I review **clean** code. |
