# Adjetivos y Pronombres Posesivos en Inglés (Possessives)

## 📌 Contexto
En inglés, existen dos formas principales de indicar posesión. La diferencia clave radica en si acompañan a un sustantivo o si lo reemplazan por completo.

1. **Adjetivos Posesivos (Possessive Adjectives)**: 
   - Siempre van **antes** del sustantivo.
   - Funcionan como un adjetivo que describe de quién es la cosa.
   - *Ejemplo:* This is **my** laptop. *(Esta es mi laptop).*

2. **Pronombres Posesivos (Possessive Pronouns)**:
   - Van **solos**, sin sustantivo después, porque reemplazan al sustantivo para evitar repeticiones.
   - *Ejemplo:* This laptop is **mine**. *(Esta laptop es mía).*

## ⚠️ Reglas de Oro (Nivel B1)

1. **El posesivo concuerda con el DUEÑO, no con la cosa poseída.**  
   A diferencia del español, en inglés no importa si el objeto es masculino o femenino, sino el género de quien lo posee.  
   - *She* loves **her** job. *(Ella ama su trabajo).*  
   - *He* loves **his** job. *(Él ama su trabajo).*

2. **Cuidado con "Its" vs "It's".**  
   - **Its** (sin apóstrofe) = posesivo de "it" (su, de una cosa o empresa).  
     *Ej: The company updated **its** policy.*  
   - **It's** (con apóstrofe) = contracción de "it is" o "it has". **Nunca** es posesivo.

3. **Los pronombres posesivos NUNCA llevan apóstrofe.**  
   - Correcto: The code is **yours**.  
   - Incorrecto: The code is ~~your's~~.

## 💻 Ejemplos en Contexto (Desarrollo de Software)

- **Adjetivo:** **Our** API uses Java 25, but **their** API still uses Java 8.  
  *(Nuestra API usa Java 25, pero su API aún usa Java 8).*
- **Pronombre:** This repository is **mine**, not **his**.  
  *(Este repositorio es mío, no de él).*
- **Combinado:** **My** code passed the tests, but **hers** failed.  
  *(Mi código pasó las pruebas, pero el de ella falló).*
