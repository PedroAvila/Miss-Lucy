# Vocabulario por tandas temáticas (B1/B2)

Complemento a `vocabulary.txt` (el diario histórico de palabras). Estas tandas están armadas para cerrar el
objetivo de [ADR 0002](../docs/decisions/0002-objetivo-b1-b2-para-diciembre.md) y
[ADR 0003](../docs/decisions/0003-criterios-concretos-b1-b2.md): vocabulario **activo** por tema, con
oración de ejemplo e IPA británica, listo para usar en una sesión de HelloTalk.

Se generan de a una, alineadas con el tema que toque hablar esa semana — no de golpe.

## Cómo se cuenta una palabra como "aprendida"

No al escribirla en el archivo — al usarla sin pensarla en una sesión real de HelloTalk sobre ese tema. Ver
el checklist de fluidez del ADR 0003.
